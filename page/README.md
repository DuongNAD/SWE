# page/ — thư mục dùng lúc thi

Đây là chỗ DUY NHẤT bạn phải đụng vào khi đã có đề.

1. Dán đề vào `de.txt` (nguyên văn, đủ mọi bảng/số liệu).
2. Mở `prompts/P4_lam_bai_khi_thi.md`, dán prompt đó + nội dung `de.txt` vào
   Gemini 3.1 Pro hoặc Claude Opus 4.6.
3. Lưu kết quả vào `out/<ngày>-<tên đề>.md`.

Muốn nhiều đề cùng lúc: tạo `de-01.txt`, `de-02.txt`… mỗi file chạy một lượt riêng.
Không nhồi 2 đề vào 1 lượt — chất lượng tụt.
